# 数据库文件

完整的安装、使用和部署指南见 [项目 README](../README.md)。

- `init.sql`：针对空 MySQL 8 数据库的完整 15 张表及七类词库定义，不含用户或单词正文。
- `../server/src/schema.sql`：应用初始化脚本使用的完整表结构，已按外键依赖排序。
- `pnpm db:init`：推荐的首次初始化入口，创建表、导入七个根目录词库文件，并创建 `.env` 中配置的管理员。
- `pnpm --dir server schema:sync`：已有安装的兼容更新，不导入词库，不替代完整版本化迁移。

先创建自有数据库并配置根目录 `.env`，再从项目根目录运行命令。仅手工导入 SQL 不会生成可登录的管理员或完整词库；重复运行 `db:init` 会更新管理员密码及系统词条。备份、生产配置和真实用户数据不得提交到公开仓库。
